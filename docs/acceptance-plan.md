# 验收与测试计划

本文件是后续产品实现的退出条件，不是已经运行完毕的测试报告。当前只有调研资料、参考检出和研究工具的验证；浏览器产品用例均待实现后执行。

## 1. 证据与测试环境

每次产品验收记录：产品 Git SHA、依赖锁文件摘要、构建命令、产物 SHA-256、浏览器完整版本、操作系统、文件 URL 开关状态、测试输入和预期/实际结果。功能未实现、测试被跳过和环境阻塞不能记为通过。

自动化采用 Playwright 的 Chromium 持久化上下文测试扩展。官方说明 Chrome/Edge 品牌浏览器的部分命令行扩展加载能力已变化，因此 CI 使用 Playwright 配套 Chromium，不把过去的启动参数当成永久有效接口。[T1]

CI Chromium 验证之后，还需在用户实际使用的 Chrome Stable 中加载安装包，按普通用户步骤完成文件 URL 权限、目录授权和浏览器重启验证。禁止使用 `--disable-web-security`、开发者日常浏览器 profile 或 DevSpace 的额外权限来伪装产品本身可用。

首轮实机重点为 macOS。Windows 文件路径、盘符与目录授权列为对外 V1 验收；如没有相应环境和结果，不宣称完成跨系统验证。其他 Chromium 浏览器仅在单独测试后列为支持。

## 2. 功能矩阵

| ID | 用例 | 验收要求 |
| --- | --- | --- |
| F01 | file URL 地址栏直接打开 | 保留原地址，自动显示正文与标题目录，不需要 HTTP 服务 |
| F02 | 文件访问权限未开/撤销 | 不白屏；解释所缺权限并给出可操作指引 |
| F03 | 中文、空格、百分号、编码后的 #/?、大小写后缀 | 正确定位文件，不能双重解码或把 fragment 当文件名 |
| F04 | UTF-8、BOM、CRLF、可选其他编码 | 正文与代码不丢失；错误编码有覆盖入口 |
| F05 | 非 Markdown、本地 HTML、普通网站 | 不错误接管，不主动扫描或读取无关资源 |
| F06 | 浏览器直接下载而非打开文件 | 说明限制，并提供文件选择/工作区入口 |
| F07 | H1–H6、标题跳级、中文/重复标题 | 正文锚点与 TOC 一致，刷新后深链接仍可用 |
| F08 | 滚动、前进后退、跨文档锚点 | 定位合理，无旧会话覆盖或意外打开重复标签页 |
| F09 | GFM 表格、任务、删除线、引用、脚注 | 显示、复制和导出语义一致 |
| F10 | 长代码、未知语言、代码含 HTML | 不执行；原文复制正确；窄屏可滚动 |
| F11 | 内联/块级数学、中文混排、非法公式 | 正常公式可读；错误局部显示，不中断整页 |
| F12 | 提示块、frontmatter、details、安全 HTML | 仅允许的显示语法生效，不改变安全策略 |
| F13 | 同目录图片、父目录资源、链接、缺失图片 | 解析和授权策略一致；扩权需明确动作；失败有占位 |
| F14 | 原文视图与阅读视图切换 | 无内容损失、不触发文件写回 |
| F15 | 文件保存、快速连续保存、删除、重建 | 只更新最新 revision，保持合理阅读位置 |
| F16 | 选择文件夹、取消、拒绝、授权过期 | 单文件模式仍可用；不得自动扫描未授权目录 |
| F17 | 最近工作区、浏览器重启、目录移动 | handle 校验与重新授权正确，无永久权限假设 |
| F18 | 大目录、深目录、隐藏项、构建目录 | 懒枚举、预算可控、默认排除符合说明 |
| F19 | 明/暗/系统主题、字号、宽度、窄屏 | TOC、表格、公式、代码与图表同步适配 |
| F20 | 键盘、焦点、可访问标签、减少动效 | 基础阅读、目录与关闭弹层不依赖鼠标 |

## 4. 安全矩阵

| ID | 输入或行为 | 预期 |
| --- | --- | --- |
| S01 | script、onerror、javascript URL、iframe、object | 不执行、不外联，不破坏允许的安全正文 |
| S02 | SVG script、事件属性、外部 href、foreignObject | 被拒绝/清洗；合法 marker、渐变与内部引用仍显示 |
| S03 | Mermaid 指令/frontmatter 尝试降低 securityLevel | 产品级安全策略不被覆盖 |
| S04 | Vega 外部数据/图片与表达式生成、ECharts 函数字符串 | 默认没有网络加载或任意 JS 执行 |
| S05 | PlantUML includeurl、远程渲染回退 | 默认不访问网络、不上传 DSL |
| S06 | Markdown 远程图片、CSS 字体、外部样式 | 默认占位，用户显式授权后才允许对应资源 |
| S07 | 伪造 postMessage、错误 sender/tab/frame/session | 不触发本地读取、设置变更或其他会话渲染 |
| S08 | 路径遍历、双重编码、近似路径前缀 | 不扩大应用允许的读取范围；不声称提供未验证的 OS 级隔离 |
| S09 | 超长 Markdown/DSL、巨量节点、深嵌套 | 预算限制或可取消降级，不依赖 Promise 超时中断同步计算 |
| S10 | 断网使用全部 P0/P1 本地样例 | 除显式授权的远程资源场景外，显示不依赖外部服务 |
| S11 | 网络记录审计 | 无 CDN 运行码、隐式上传、远程字体、后台埋点或预取 |
| S12 | 最近路径/内容缓存/目录 handle | 仅本机存储；清理入口有效；不进入 sync 或 Release |

安全用例需在最终打包产物执行，不只检查源码中是否出现某个 sanitize 函数名称。离线模式测试与正常联网时的“无隐式请求”测试都要执行。

## 5. 生命周期与性能

- 关闭再重开浏览器、Service Worker 空闲停止后重新唤醒、多标签页并行阅读、标签隐藏/恢复、文档切换期间任务取消。
- 一个图表错误不能让所有图表都消失；旧 revision 返回不能覆盖新内容。
- 按技术方案的 1 MB、5 图、100 图、10 MB 和超预算场景记录 P50/P95、主线程长任务、内存与实际网络请求。
- 重复打开/关闭文档与全屏图表后检查监听器、Blob URL、缓存和 offscreen 会话释放，排查内存累积。
- 打印与导出必须渲染全部目标图表，有完成/失败统计，不遗漏离屏内容。

性能目标属于验收目标，未有结果前不得在 README 宣称“秒开”“零卡顿”或某个已达百分位。

## 6. 发布阻塞条件

以下任一未满足，不发布正式 V1：

1. 本地地址栏直读、权限拒绝恢复、甘特图、时序图、TOC 或已承诺的文件夹树存在阻断故障。
2. 依赖网络执行代码、默认上传文档、任意本地文件读取接口泄露，或安全语料可触发脚本执行。
3. 产品构建依赖本机的 `参考工程/`、未提交文件、私有绝对路径或未锁定的关键依赖。
4. GPL 与第三方声明不完整，来源不清，或包里包含日志、凭证、浏览器 profile、真实私人文档。
5. 文档声称的支持平台/语法/导出功能没有对应测试结果；有阻塞却标记“全部完成”。

正式 Release 附功能状态与已知限制；后续新增引擎必须同时新增语料、权限影响评估和依赖许可证记录。
